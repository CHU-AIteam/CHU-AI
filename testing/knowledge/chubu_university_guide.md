# 中部大学の概要

- 中部大学は、8学部27学科4専攻がワンキャンパスに集まる総合大学。
- 学部の枠を超え、文理が融合する学びを重視している。
- 建学の精神を体現した「あてになる人材」の育成を目指している。
- 学生が自分らしく学び、学友と語り合い、活動を共にしながらキャンパスライフを送ることを重視している。

# 学びの特徴

- 中部大学は、工学部のみの単科大学として始まり、現在は中部圏屈指の総合大学へ発展している。
- 幅広い学問領域をカバーする学部学科が連携している。
- 高度な専門性と柔軟な応用力を兼ね備えた人材の育成を目指している。

- 2024年春卒の実績として、就職希望者数2,092人、就職者数2,088人と案内されている。
- 求人企業数は2024年度実績で22,132社。
