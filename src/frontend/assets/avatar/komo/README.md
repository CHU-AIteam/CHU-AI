# Komo avatar assets

`komo-puppet.png` is the authorized television mascot sprite used by
`avatar-puppet.js`.

`komo-face-blank.png` supplies the clean pale-blue television screen behind
the runtime-drawn eyes, eyebrows, mouth, and emotion effects.

Both images are local transparent PNG files. PixiJS splits the character at
runtime into the television head, antenna, torso, arms, and legs.
