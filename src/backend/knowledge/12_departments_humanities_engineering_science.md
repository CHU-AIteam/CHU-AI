## 人文学部 メディア情報社会学科

### 概要

- キャッチ: 価値のあるメディア情報を選択する視点を養い、効果的に提供・発信するスキルを身につける。
- 2コース表記: 「情報社会コース」「メディア情報コース」。

### 学びのキーワード

- メディア化
- 情報キュレーション
- コンテンツ・クリエーション（実写・アニメ・CG・音響・ゲーム等）
- 情報デザイン
- 地域貢献

### 4年間の流れ

| 年次 | 内容 |
| --- | --- |
| 1年次 | 大学・学科での学びの理論的基礎をしっかり構築 |
| 2年次 | 専門分野の基幹的科目で専門的知識やスキルを修得 |
| 3年次 | 高度な専門知識を身につけてプロジェクト（ゼミ）で実践 |
| 4年次 | 集大成として卒業研究に取り組み、その先の人生を設計 |

### 特色ある学び

- 新入生向けプログラムとして「那覇映像制作研修」の掲載あり。
- 「アニメーション制作技法」「27スタジオ」「メディア情報社会プロジェクト」などの実践活動が掲載されている。

### 要確認

- 取得が期待される資格の細かい注記・進路一覧は文字が小さいため要確認。

## 工学部 機械工学科

### 概要

- キャッチ: 機械を極め、未来を創る。
- 学びの方向: 数学・物理学を基盤に、設計・加工・実習を通じて実践的なものづくり能力を養う。

### 学びのキーワード

- ものづくり
- 機械設計
- CAD/CAM/CAE
- 工作機械
- エネルギーシステム

### 4年間の流れ

| 年次 | 内容 |
| --- | --- |
| 1年次 | 機械工学の基礎は、機械に触れ、機械を知ることから |
| 2年次 | 機械に関わる物理現象を学ぶ |
| 3年次 | 設計開発に求められる専門能力を身につける |
| 4年次 | 卒業研究で、初めての「研究開発」に取り組む |

### 特色ある学び

- 「機械創成実習」「機械工学実習」「CAD/CAM/CAE」の掲載あり。
- 「HOKUTO FACTORY INNOVATOR LAB（工学デザインルーム）」の掲載あり。
- 先端技術シンポジウムでの優秀論文賞受賞事例の掲載あり。

### 要確認

- 取得が期待される資格の全項目、主な進路一覧の企業名は要確認。

## 工学部 都市建設工学科

### 概要

- キャッチ: 都市建設のプロになるための確実な知識・技術と柔軟なデザイン能力を修得。
- JABEE認定プログラム表記あり（国際的に通用する技術者育成）。

### 学びのキーワード

- 土木・インフラ・社会基盤
- まちづくり
- 防災・減災
- 都市環境
- 建設・維持管理・更新

### 4年間の流れ

| 年次 | 内容 |
| --- | --- |
| 1年次 | 専門科目を理解するための教養・基礎知識を学ぶ |
| 2年次 | 創成科目がスタートし、専門科目も本格化 |
| 3年次 | 卒業研究を軸に創成・専門科目が深化 |
| 4年次 | 卒業研究の総仕上げと、より高度な学修 |

### 特色ある学び

- 「社会で即戦力となる実践力を育む教育体制」「産学連携」の掲載あり。
- LINE活用による情報共有・学生支援、サークル活動に関する掲載あり。

### 要確認

- 資格欄の受験条件注記、進路一覧の詳細企業名は要確認。

## 工学部 建築学科

### 概要

- キャッチ: 「人間」と「環境」を中心に豊かな社会を構築し、地域の核となり社会貢献できる技術者を育成。
- 学びの方向: 建築計画・構造・環境・デザインを横断的に学ぶ。

### 学びのキーワード

- 建築の企画・設計と施工
- 構造解析
- 環境設備
- デザイン
- CAD
- リノベーション

### 4年間の流れ

| 年次 | 内容 |
| --- | --- |
| 1年次 | 建築学の導入となる実習、基礎知識を学ぶ |
| 2年次 | 建築学の基礎となる4分野とデザインを学ぶ |
| 3年次 | 目指す進路から卒業研究の専門分野を選定 |
| 4年次 | 卒業研究をとおして専門性を高める |

### 特色ある学び

- 「建築CAD演習」「海外建築研修」の掲載あり。
- 環境・構造・材料実験環境が紹介されている。

### 要確認

- 資格欄の細目（受験年数条件等）と進路一覧の詳細は要確認。

## 工学部 応用化学科

### 概要

- キャッチ: 化学を環境に生かす視点で、問題解決能力の高い化学技術者・研究者を育成。
- JABEE認定プログラム表記あり。

### 学びのキーワード

- 材料化学・環境化学工学
- 新素材
- 有機化学・高分子
- 高校教員（理科）

### 4年間の流れ

| 年次 | 内容 |
| --- | --- |
| 1年次 | 化学への興味を引き出し、応用化学の基礎を身につける |
| 2年次 | 各分野の基礎教育と少人数実験科目で力をつける |
| 3年次 | コース制教育で、技術者に必要な応用化学の知識を深める |
| 4年次 | 卒業研究をとおして高い専門性と実践力を身につける |

### 特色ある学び

- 「応用化学創成実験」「ロボット化学者」などの掲載あり。
- 教職課程から国家資格までの進路支援が掲載されている。

### 要確認

- 取得が期待される資格の全項目（国家資格名・条件）は要確認。

## 工学部 情報工学科

- キャッチ: 情報化社会の最先端で活躍できる情報工学のプロになる。
- 学びの方向: 設計・実装・評価・改善を行う情報技術者としての基礎力と実践力を養う。

### 学びのキーワード

- プログラミング
- AI（人工知能）
- Web
- IoT
- システムエンジニア

### 4年間の流れ

| 年次 | 内容 |
| --- | --- |
| 1年次 | 情報工学に必要な土壌をつくる |
| 2年次 | プログラミング技術と専門知識を幅広く学ぶ |
| 3年次 | セミナーや実験で実践力・想像力を養う |
| 4年次 | 卒業研究において実践力を発展させる |

### 特色ある学び

- 「創成科目」「情報工学実験」の掲載あり。
- 学生構築システムとして「未来創造型実験システム」の紹介あり。

### 要確認

- 資格欄の全項目（高度情報処理資格等）と主な進路企業一覧は要確認。

## 工学部 電気電子システム工学科

### 概要

- キャッチ: 電気・電子・情報通信のマルチな専門性を備え、社会が最も必要とする技術者へ。
- 学びの方向: 電気エネルギー技術とエレクトロニクス技術を核に、実験重視で応用力を養う。

### 学びのキーワード

- 発送配電
- 電子デバイス
- 制御機器
- 電子回路
- 半導体
- 情報通信
- EV（電気自動車）

### 4年間の流れ

| 年次 | 内容 |
| --- | --- |
| 1年次 | 学部共通・専門科目の基礎を学び、広く知る |
| 2年次 | 電気系・電子系の基礎を学び、実習・実験に取り組む |
| 3年次 | 希望する専門分野を選び、学びを深める |
| 4年次 | 卒業研究や共同研究に取り組む |

### 特色ある学び

- 実験が充実したカリキュラム、研究室活動、資格取得・就職支援の掲載あり。
- 「スマートな社会」の実現に向けた学びの図解掲載あり。

### 要確認

- 資格名称の細目（無線・電気工事・主任技術者等）と条件注記は要確認。

### 学びのキーワード

- データサイエンス

| 2年次 | 学科専門教育科目で数理科学と物理科学の世界へ |

- 深層学習

- 飛行機
- ロケット
- 人工衛星
- ドローン
- ジェットエンジン
- 先端材料・構造
- CAD
- データサイエンス

| 年次 | 内容 |
