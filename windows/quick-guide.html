コモの使い方

設置PCの担当者向け / この1枚で、起動・終了・知識更新

朝：電源を入れ、Windowsにログイン

起動の進み具合が表示されます。準備ができると、コモの画面が開きます。

画面が閉じていたら、デスクトップの 「コモ管理」→「コモを開く」 を押します。

知識を更新するとき

USBを挿す→ファイルを選ぶ→内容を確認して反映
  1. 資料を入れたUSBを、このPCのUSB差込口へ挿します。
  2. 「コモ管理」→「知識を更新」 を押します。
  3. USB内のWord・テキスト・Markdownファイルを選びます。
  4. 読み取った内容を確認します。同じ名前があるときは、追加か置き換えを選びます。
  5. 「この内容をコモに反映する」 を押し、完了の表示が出るまで待ちます。
  6. コモに質問して内容を確認し、USBを安全に取り外します。

更新後はUSBを抜いて使えます。元へ戻したい場合は、知識更新画面の 更新履歴・元に戻す を使います。

夜：利用を終える

Ctrl + Alt + K（または Alt + Tab）で「コモ管理」に戻り、「本日の利用を終了」 を押します。終了の表示が出たら、Windowsをシャットダウンできます。

困ったとき

管理画面の案内を見て 「再試行」 を押します。改善しない場合は「保守・困ったとき」→「問い合わせ用の記録を保存」で担当者に渡します。

この案内はUSBメモリーの図解です。実際の差込口はPCに合わせて「コモ更新用」のシールを貼って示してください。初回設定・接続情報の変更・アプリ更新は担当者が行います。
