# コモの使い方

毎日の操作は、パソコンのデスクトップにある **「コモ管理」** から始めます。

## はじめて使う

1. 設置を担当した人から受け取った **CHU-AI** フォルダを開きます。中にある **「コモの初回設定」** をダブルクリックします。
2. 「コモをつなぐためのコード」の欄が出たら、設置を担当した人から受け取ったコードを貼り付けます。
3. **「準備を始める」** を押します。いま何を準備しているかが画面に出ます。
4. 試しの質問に答えられると、コモが開きます。次からはデスクトップの **「コモ管理」** を使います。

## 毎日使う

| やりたいこと | 押すボタン |
|---|---|
| 来場者が使う画面を出す | コモを開く |
| コモが答える内容を変える | 案内を更新する |
| コモを閉じる | 今日の利用を終える |

全画面のコモから戻るには、**CtrlキーとAltキーを押したままKキーを押します**。反応しないときは、Altキーを押したままTabキーを押して「コモ管理」を選びます。

「今日の利用を終えました」と表示されたら、パソコンの電源を切って大丈夫です。

## USBのWordで案内を変える

1. 案内を書いたWordを入れたUSBを挿します。
2. **「案内を更新する」→「ファイルを選ぶ」** を押します。開いた画面の「PC」からUSBを探し、Wordを選びます。
3. 同じ名前の案内があるときは、**「今の案内を入れ替える」** か **「別の案内として追加する」** を選びます。入れ替えるときは、変わる箇所が表示されます。
4. 内容を確かめてチェックを入れ、**「この案内をコモの回答に使う」** を押します。
5. 終わったら **「コモに聞いて確かめる」** を押して、案内どおりに答えるかを試します。USBは取り外して大丈夫です。

Wordの画像の中にしかない言葉は読み取れません。コモに答えてほしいことは、本文にも書いてください。新しく案内を書くときは、画面にある **「案内を書くためのWordのひな形」** を使えます。

## 前の案内に戻す・USBに保存する

- **「今の案内を直す」** では、1つの案内を選んで書き直せます。「この案内の利用を止める・前の内容に戻す」を開くと、その案内だけ利用を止めたり、前の内容に戻したりできます。
- **「以前の案内に戻す」** では、選んだ日の内容にすべての案内をまとめて戻せます。
- **「USBに保存・USBから戻す」** では、案内とおみくじの回数を保存できます。「案内とおみくじの回数をUSBに保存する」を押し、保存場所としてUSBを選びます。「ダウンロード」に保存されたときは、保存したファイルをUSBに移してください。戻すときは「USBから戻すファイルを選ぶ」を押し、保存した日を見てから「保存した内容に戻す」を押します。

## 困ったとき

使う準備ができなかったときは、画面に出る案内に沿って **「もう一度試す」** などのボタンを押します。**「コモとおみくじを開く」** が出ているときは、質問への回答をお休みした状態でコモを開けます。

直らないときは **「担当者に渡す記録を保存」** を押し、保存したファイルを設置を担当した人に渡します。普段の画面では **「設定・困ったとき」** の中にあります。

<summary>設置・配布を担当する方へ</summary>

- Git、Microsoft Edge、Docker Desktopを準備し、Docker Desktopの初回案内とLinuxコンテナーの設定を済ませます。設置用のWindowsアカウントで、移動しない場所にリポジトリを置きます。更新作業後に、以前の全画面と「コモ管理」を閉じてから「コモの初回設定」を開きます。従来の windows/setup.cmd でも同じ画面が開きます。
- 「コモをつなぐためのコード」はGeminiのAPIキーです。既存PCは保存済みのコードを選べます。「別のコードを使う」で入力欄が開きます。src/.env の既存の接続設定や利用中のログ保存先を引き継ぎます。新規設定の回答モデルは Gemini 2.5 Flash-Lite です。診断記録の原因が gemini_model の場合は、src/.env の GEMINI_MODEL を確かめます。
- 自動で開く設定は、同じWindowsユーザーのログイン時に働きます。最初の設定のチェックを外して更新するか、windows/disable-autostart.cmd で解除できます。
- 「新しい更新があるか調べる」は配布先を確認し、「コモ本体を更新する」はGitの追跡先から取得して切り替えます。来場者がいない時間に行ってください。準備に失敗した場合は保持した前の版への復旧を試します。「ひとつ前のコモに戻す」には、その版のDockerイメージが必要です。旧版の全画面が残った場合はAltキーを押したままF4キーを押して閉じます。
- 案内はWord文書（.docx）、テキスト（.txt）、Markdown（.md）を1件ずつ、8MBまで読み取れます。案内と集計を保存するファイルには、原本と直近100件の履歴を含み、上限は64MBです。戻すときは検索用の準備にGeminiへの接続が必要です。接続コード、チャット履歴、パソコンの設定は別に管理してください。
- 運用時の案内は data/knowledge/、検索用のデータはDockerの永続ボリューム、操作記録は data/windows-launcher/ に置きます。おみくじの回数は同じEdgeの利用者設定と http://127.0.0.1:8000 に保存されています。
- 設置後は、ログイン後に自動で開けること、全画面から管理に戻れること、USBの案内を入れ替えられること、利用を終えられることをWindowsで通して確かめてください。
