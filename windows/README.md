# Windows専用PCのコモ管理

日常操作は、設置PCのデスクトップにある **コモ管理** から行います。

## 初回設定と既存PCの更新

1. コモを日常利用するWindowsアカウントで、Gitから取得したCHU-AIフォルダを開きます。Git・Microsoft Edge・Docker Desktopを用意し、Docker Desktopの初回案内とLinuxコンテナーの設定を済ませてください。
2. 以前から使っているPCでは、古いコモの画面を一度閉じます。公開された更新を通常どおり取得します。
3. **windows\setup.cmd**（種類が「Windows コマンド スクリプト」の setup）をダブルクリックします。
4. 「設定して動作を確認」を押します。既存のキーを使う場合は空欄のまま進めます。初回や差し替えの場合は、Geminiのキーを入力欄に貼り付けてください。
5. 必要ソフト・接続・知識の準備・試しの質問を確認できると、コモが開きます。デスクトップに「コモ管理」「コモの使い方」が作られます。
6. 自動起動を選んだ場合は、Windowsへ再ログインし、コモが開くことを確認します。

インストール先は今後動かさないフォルダにします。既存の src\.env は管理用キー・専用PCの設定と、入力欄で指定したGeminiキーを更新して使います。外部のログ保存先を利用する場合は、既存の接続設定を引き継いでください。自動起動は現在のWindowsユーザーに登録し、タスク登録が利用できない場合は、そのユーザーのスタートアップフォルダーを使います。設定画面のチェック欄または windows\disable-autostart.cmd から解除できます。

新しく作成した設定では、回答モデルに Gemini 2.5 Flash-Lite を使います。既存PCで「設定されているGeminiモデルを利用できません」と出た場合は、設置担当者が src\.env の GEMINI_MODEL を確認してから再試行してください。[Geminiのモデル提供状況](https://aistudio.google.com/docs/deprecations#gemini-2.5-flash-models)

## 普段の操作

| ボタン | 操作 |
|---|---|
| コモを開く | 準備済みの版を使って起動します。すでに開いていればその画面を前面に出します |
| 知識を更新 | USBの資料を読み取る画面を開きます |
| 本日の利用を終了 | コモ専用画面を閉じて、このプロジェクトのサービスを停止します |

全画面のコモからは **Ctrl + Alt + K** で管理画面に戻れます。効かない場合は **Alt + Tab** で「コモ管理」を選びます。サービスの終了後はWindowsのスタートメニューからPCをシャットダウンできます。

準備中は処理の段階と経過時間が表示されます。処理が失敗したら、管理画面に残った案内を見て「再試行」または「初回設定・接続を直す」を選びます。「コモとおみくじだけ開く」が選べる場合、チャットを休止した状態で来場者にコモを開けます。「コモを開く」で回答の確認に成功すると質問を再開します。

## USBで資料を更新

1. USBを挿し、「知識を更新」→「ファイルを選ぶ」を押します。Word（.docx）、テキスト（.txt）、Markdown（.md）を1件ずつ読み取れます。
2. 読み取った内容を確認します。同じ名前がある場合は「この資料を置き換える」か「新しい資料として追加する」を選びます。置き換えでは、変更された行が確認できます。
3. 必要なら文章を直し、確認欄にチェックして「この内容をコモに反映する」を押します。
4. 完了後、「コモで質問して確認する」を押し、USBを取り外します。

Wordの本文・見出し・表を読み取ります。画像・スキャンに書かれた文字は取り込みません。「登録済みの知識を編集」→資料を選択→「この資料の利用設定・履歴」から、期間が終わった案内の利用停止・再開と、資料1件の復元ができます。「更新履歴・元に戻す」は知識全体を選んだ版へ戻します。

## バックアップ

「知識を更新」→「バックアップ」→「バックアップを保存」で、USBなどに保存します。ブラウザーがダウンロードした場合は、そのファイルをUSBへ移します。資料、原本、直近100件の知識履歴と、同じEdgeプロファイルで集計したおみくじ回数を保存します。保存できるファイルは64MBまでです。

復元は同じ画面の「復元するファイルを選ぶ」から日付と件数を確認して実行します。復元後に回答できるよう検索データを作り直すため、Geminiへの接続が必要です。完了するまで今の知識を使い続けます。集計付きのファイルを復元すると、表示する回数もその時点に戻ります。

バックアップには接続キー、Windowsの設定、チャット履歴を含めません。PCを交換したときは接続設定を入れ直し、この画面からファイルを復元します。

## 保守・困ったとき

- 「再起動」は現在のアプリの版で開き直します。
- 「更新の有無を確認」はGitから配布版の情報を取得します。「アプリを更新」は追跡ブランチを fast-forward で取得し、イメージを準備してから切り替えます。使っている人がいない時間に実行してください。
- 取得した版と実行中の版を保守欄に表示します。前の版があり、新しい版の準備や回答確認が失敗した場合は、前の版への復旧を試します。「前の版で開く」から手動でも切り替えられます。元のDockerイメージが残っていることが必要です。プログラムの切り替えで知識の版とおみくじ集計を変更することはありません。
- 移行前の旧版に戻った場合、そのコモ画面は Alt + F4 で閉じてから利用を終了してください。
- 直らない場合は「問い合わせ用の記録を保存」で、状態と直近の失敗内容をテキストに保存し、担当者へ渡します。

設置PC内の動作記録は data/windows-launcher/ に保存します。検索データはDockerの永続ボリューム、資料・履歴は data/knowledge/、おみくじ集計はEdgeの同じプロファイル・URLに保存します。これまでと同じ http://127.0.0.1:8000 を開くことで集計を引き継ぎます。

Windows実機では、初回設定、ログイン後の自動起動、画面の再利用と終了、USBからの反映・復元、通信断時の案内を確認してください。ランチャーはWindows PowerShell 5.1とWPFを使い、別途Pythonをインストールする必要はありません。
